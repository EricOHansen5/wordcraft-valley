# Sound It Out, Don't Guess — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make sounding out the quickest way to the prize: close the places where guessing pays, give the prize only for a clean first try, and switch on an in-order Sound Shield only while he is guessing.

**Architecture:** One new module, `Guess` (after `Skills`, before `soundShield`), keeps `state.guess` and gives each word a tracker that the crate loop and the `Read` kit report to; `Skills.slow` becomes a view of guess mode so every existing caller follows it. The crate loop (`openWord`, `checkBuild`, `blend`, `miss`, `renderPicks`, `succeed`), `renderListen`, `soundShield` and `Read.pic/wordPick/sentence/build` change in place.

**Tech Stack:** `app/index.html` (single-file game, inline JS/CSS), Playwright suites via `tests/lib.js`, `tools/progress.js`, the Kokoro voice pipeline.

**Spec:** `docs/superpowers/specs/2026-10-19-guessing-design.md`

## Global Constraints

- Kind words; a wrong answer never takes anything away ("no boost this time"): a prize that waits is not taken; gems already earned are never removed.
- Older iPad Safari: no `?.`, `??`, `.at()`, `structuredClone`, top-level await, CSS `:has()`.
- Never break old saves: `state.guess` is added through `def()` with defaults; nothing renamed; `state.rushes`, `stats`, `recent`, `skills` keep their meaning.
- Every new fixed spoken line gets a clip (`npm run voice:extract`, `gen.py`, `index.py`).
- Tests find answers through `host.dataset.ans` / `dataset.tiles`: keep them.
- Never put a `//` comment inline before more code on the same line. Edits by script file, not inline `node -e` with backslashes.
- Out of scope: Jobs kits, the Gem Mine word stone and shop, Word Wilds, the mine boss, the Quest Temple (they only follow `Skills.slow` as today).

## Review Focus

1. A brand-new player's first crate with a miss (the tour) still gets the prize and the tour still advances (`Coach.reach("read")`): during the tour (`state.tour<TOUR.length`) every word pays the prize. — test in Task 5.
2. After a word with misses he stays in the crates (the waiting-prize card is a sheet he closes), and Home does not come back over him (Home returns 350 ms after the Modes stack empties). — test in Task 5.
3. Hear it hides the spelling without breaking Blend it: `blend()` treats `#letters` with `display:none` as "building", so hiding must use a class (visibility), not `display`. — test in Task 3.
4. An upgrade word (`pendingUpgrade`, gems already paid) still finishes the upgrade after misses. — test in Task 5.
5. Guess mode survives a reload, and an old save without `state.guess` loads with it off. — test in Task 1.

**Interfaces:**
- Produces:
  - `state.guess = {on:false, last:[], clean:0, days:{}}` (`last`: up to 5 booleans, true = guessed; `clean`: clean first tries in a row; `days[YYYY-MM-DD]`: guessed words that day).

  - A word is a guess when: a wrong pick before any `heard()`; or 2+ `wrongTile()`; or a wrong pick within 2000 ms of `shown`.
  - `Guess.on() -> boolean`; `Guess.set(v:boolean)` (tests and the old `Skills.slow=` setter).
  - `finish`: push the guess flag into `last` (keep 5); if guessed, `days[today()]++`; `clean = clean? clean+1 : 0`; turn on when `last` has 2+ guesses; turn off (and empty `last`) when `clean>=5`. `save()`.
  - `Skills.slow` reads `Guess.on()`; setting it calls `Guess.set`. The old 0.9 s rule still counts `state.rushes` but no longer sets anything.

**Interfaces:**

- Produces: crate `cur._g` = the word's tracker (created in `openWord` for every rung; Tasks 3-6 use it); in `Read.build`, a local tracker.
- Behaviour: the next empty slot has class `next` (CSS: the existing glow look, e.g. the `.hint` ring). A bank tile for the right sound (compare `soundOf` and `tileText`, as `Read.build` does) fills that slot, says its sound, is marked `used`. A wrong tile: does not fill; it gets class `bad` for 500 ms, says its own sound, then `stretchTo(w, i)` plays the word's first `i+1` sounds as one stretched stream (`Sound.stream(w.p.slice(0,i+1))`, the way `blend()` does, no word at the end); `misses++`, `cur._g.wrongTile()`, `Skills.result(cur,{ok:false,wrongIdx:[i],placed:[ph],ms})`. After 2 misses on the same slot the right bank tile gets `hint`. Nothing is ever placed for him. Filled slots are no longer tappable to undo (each placed tile is right). When the last slot fills: the existing success path (`good`, chime, word said, `succeed`). `checkBuild`'s "send wrong tiles back / place the first sound" code goes. Tapping any tile counts as `heard()`.
- `stretchTo(w,i)` is a new top-level helper next to `blend()`, signature `stretchTo(w:Word, i:number) -> Promise<void>`.
